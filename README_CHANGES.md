# Vangcur — আপডেটেড ফাইল

এই zip-এর ফোল্ডার-স্ট্রাকচার তোমার রিপোর ঠিক একই পাথ অনুসরণ করে — শুধু এক্সট্র্যাক্ট করে
প্রতিটা ফাইল তোমার রিপোর একই পাথে replace করে দাও, তারপর `npm run build` চালিয়ে দেখো।

## কী বদলেছে

- **lib/linkedText.tsx** — `**bold**` ও `*italic*` এখন সঠিকভাবে রেন্ডার হয় (আগে শুধু
  লিংক পার্স হতো, বোল্ড/ইতালিক-এর raw `**`/`*` অক্ষর দেখাত)। raw emoji-ও এখান থেকে
  স্ট্রিপ হয়ে যায় (guide পেজের জন্য — প্রোডাক্ট পেজের Feature emoji এটার বাইরে,
  সেটা আলাদা কম্পোনেন্টে হ্যান্ডেল হয়)।
- **app/components/guides/GuideIcons.tsx** — গাইড পেজের সেকশন-হেডিং-আইকনের জন্য ২১টা
  নতুন SVG আইকন যোগ হয়েছে (wallet, wrench, smartphone, scale, layers ইত্যাদি)।
- **app/components/guides/GuideBlocks.tsx** — `BlockHeading` এখন হেডিং-এর পাশে একটা
  ব্র্যান্ড-কালার আইকন-সার্কেল দেখায় (প্রোডাক্ট পেজের SectionHeading-এর মতো)। Hero
  ব্লকের top padding মোবাইলে একটু টাইট করা হয়েছে (ব্রেডক্রাম্ব সরে যাওয়ায়)।
- **app/product/[slug]/ProductDetailClient.tsx** — Power/Packaging info-box-এর দুটো
  raw emoji (🔌📦) SVG আইকনে বদলানো হয়েছে। Feature বুলেটের raw-emoji-icon আচরণ
  **অপরিবর্তিত/আগের মতোই** রাখা হয়েছে (ইচ্ছাকৃতভাবে — সাইট-মালিকের অনুরোধে)। এছাড়া
  ছোট একটা bug fix: dynamic info-box-এর বহু-লাইন বডি টেক্সট আগে এক লাইনে জোড়া লেগে
  দেখাত (`\n` রেন্ডার হতো না) — এখন লাইন-ব্রেক ঠিকমতো দেখায়।
- **app/[...segments]/GuidePageClient.tsx** — ব্রেডক্রাম্ব নেভ ("হোম / পেজ-টাইপ")
  সম্পূর্ণ বাদ দেওয়া হয়েছে ৫টা গাইড-টেমপ্লেট পেজ থেকে (সাইট-মালিকের সরাসরি অনুরোধে)।
- **types/guides.ts** — `BaseBlock`-এ নতুন ঐচ্ছিক `headingIcon?: string` ফিল্ড যোগ
  হয়েছে (উপরের আইকন সিস্টেমের জন্য)।

## গুরুত্বপূর্ণ
এই সেশনে `app/product/[slug]/ProductDetailClient.tsx`-এর Feature-বুলেট আইকন একবার
বদলানো হয়েছিল, পরে সাইট-মালিকের অনুরোধে ঠিক আগের অবস্থায় ফিরিয়ে দেওয়া হয়েছে — তাই
এই ফাইলে Feature-সংক্রান্ত অংশে কোনো নেট পরিবর্তন নেই, শুধু Power/Packaging বক্স দুটো
আর info-box লাইন-ব্রেক ফিক্স নতুন।
