Vangcur — Auth UI Fix Pack
==========================

এই জিপে ৩টা ফাইল আছে, প্রতিটার পাথ ঠিক তোমার রিপোর মতোই সাজানো:

1. app/globals.css
   -> শেষে autofill (Chrome/Edge saved email/password) ব্যাকগ্রাউন্ড ফিক্স যোগ করা হয়েছে

2. app/components/auth/LoginModal.tsx
   -> লিংক কালার (পাসওয়ার্ড ভুলে গেছেন / রেজিস্ট্রেশন করুন / লগইন করুন) brand-primary নীল করা হয়েছে
   -> "মনে রাখুন" লেবেলের কালার ঠিক করা হয়েছে
   -> "ইমেইল চেক করুন" success পপআপের স্পেসিং টাইট করা হয়েছে

3. app/reset-password/ResetPasswordClient.tsx
   -> পাসওয়ার্ড পরিবর্তন সফল হওয়ার popup-এ "নতুন পাসওয়ার্ড সেট করুন" টাইটেল হাইড করা হয়েছে
   -> চেকমার্ক আইকন ও মেসেজ সুন্দরভাবে center-align/resize করা হয়েছে

বসানোর নিয়ম:
GitHub রিপোতে গিয়ে প্রতিটা ফাইলকে ঠিক এই একই নামে ও একই পাথে থাকা পুরনো ফাইলটার
জায়গায় replace/upload করে দাও (path এই জিপের ফোল্ডার স্ট্রাকচারের সাথে হুবহু মিলবে)।
তারপর Vercel-এ deploy হয়ে যাবে যথারীতি।

নোট: রিসেট-লিংক বারবার ব্যবহারযোগ্য থাকার (single-use না হওয়ার) বিষয়টা এখনো
ফিক্স করা হয়নি — সেটা তুমি চাইলে জানিও, ওটা আলাদাভাবে সাবধানে করতে হবে।
